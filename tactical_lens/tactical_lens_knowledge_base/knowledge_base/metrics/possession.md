# 控球与传球指标 (Possession & Passing Metrics)

## 1. OBV (On-Ball Value) 持球价值

**定义**：StatsBomb 独有的指标。衡量每次触球动作对球队进球/失球概率的影响。

**核心理念**：
- 不是所有触球都等价——某些触球比其他的更"有价值"
- OBV 衡量每次动作后，球队得分概率的变化（+/- 影响）
- 正值 = 这次触球让球队更接近进球
- 负值 = 这次触球让球队离进球更远了

**计算方式**：
- 基于持球状态模型（possession-state model）
- 考虑球场位置、防守压力、比赛情境等

**战术意义**：
- 高 OBV 球员 = 每次触球都在创造价值
- OBV 排名反映球员对进攻的真实贡献
- 可以比较不同位置的球员价值

**训练关联**：
- 决策训练（选择高价值的触球方式）
- 传球选择训练
- 进攻意识训练

**数据来源**：StatsBomb 独占

## 2. Pass Types 传球类型

**StatsBomb 传球事件细分**：

| 类型 | 定义 |
|------|------|
| Ground Pass | 地面传球 |
| High Pass | 高空传球 |
| Low Pass | 低平球传球 |
| Cross | 传中 |
| Through Ball | 直塞球 |
| Switch | 横向转移球 |
| Long Ball | 长传 |
| Short Pass | 短传 |
| Lay-off | 回做球 |
| Cut-back | 倒三角传球 |
| Through Ball | 直塞（打穿防线） |
| Outswinging | 外旋球（角球等） |
| Inswinging | 内旋球 |
| Straight | 不旋转 |

**进阶传球标签**：
- **Pass under pressure**：压力下的传球
- **Pass with body part**：传球使用的身体部位
- **Pass height**：传球高度
- **Pass outcome**：传球结果（成功/失败/被拦截/出界）

**战术意义**：
- 传球类型分布反映球队风格
- 高 Cross 数 = 依赖边路传中
- 高 Through Ball 数 = 直塞打法
- 高 Switch 数 = 横向转移多

**训练关联**：
- 特定传球技术训练
- 压力下的传球训练
- 传球选择训练

## 3. Progressive Passes 推进传球

**定义**：将球向对方球门方向推进至少 10 米（或推进到禁区内）的传球。

**计算方式**：
```
Progressive Pass = 传球终点到球门的距离比起点到球门的距离近 ≥10m
```

**细分**：
- Progressive Passes from Deep：后场发起的推进传球
- Progressive Passes to Final Third：推进到前场的传球
- Progressive Passes into Box：推进到禁区的传球

**战术意义**：
- 反映球队的纵向推进能力
- 高数值 = 打法直接、有穿透力
- 低数值 = 横向传导多、缺少纵向威胁

**训练关联**：
- 中场推进训练
- 破线传球训练
- 纵深进攻训练

---

## 4. Line-Breaking Passes 破线传球

**定义**：传球路线穿过至少一名对方防守球员的传球。

**StatsBomb 360 特有**：需要 freeze-frame 数据来判断传球路线是否穿过防守球员。

**战术意义**：
- 破线传球 = 直接穿透对方防线
- 高数值 = 球队有很强的穿透能力
- 反映中场球员的传球视野和技术

**训练关联**：
- 破线传球专项训练
- 中场接应跑位训练
- 传球时机训练

---

## 5. Ball Receipts in Space 空位接球

**定义**：在无防守压力区域接球。

**StatsBomb 360 特有**：通过 freeze-frame 数据判断接球时周围是否有防守球员。

**战术意义**：
- 高空位接球 = 跑位好、找到空间
- 反映球员的无球跑动能力
- 反映中场组织者的传球精度

**训练关联**：
- 无球跑位训练
- 接应训练
- 空间意识训练

---

## 6. xPass (Expected Pass) 预期传球

**定义**：每次传球的完成概率。

**计算方式**：基于传球距离、角度、压力、传球类型等。

**进阶用法**：
- **xPass Completed %**：实际传球成功率 vs 预期传球成功率
  - 实际 > 预期 = 传球质量高于平均
  - 实际 < 预期 = 传球质量低于平均
- **xPass vs Actual comparison**：比较球员的真实传球能力和传球选择

**战术意义**：
- 高 xPass 完成率 = 传球技术好
- 低 xPass + 高风险传球 = 传球选择激进

**训练关联**：
- 传球精度训练
- 传球选择训练（风险 vs 安全）

---

## 7. Pass Network 传球网络

**定义**：球队内部球员之间的传球连接关系图。

**构建方式**：
- 节点 = 球员
- 边 = 传球次数/传球价值
- 边粗细 = 传球频率

**分析方法**：
- 最密集的连接 = 核心配合关系
- 孤立节点 = 该球员参与度过低
- 网络密度 = 球队整体配合流畅度

**战术意义**：
- 反映球队的进攻重心（哪侧球员连接多）
- 反映战术执行（是否按预期配合）
- 反映球员孤立问题（某球员是否被限制）

**训练关联**：
- 配合训练（针对特定连接）
- 接应跑位训练
- 战术演练

---

## 8. Possession by Zone 分区控球

**定义**：在各场地区域的控球时间和比例。

**StatsBomb 分区**：
- Defensive Third（后场三分之一）
- Middle Third（中场三分之一）
- Attacking Third（前场三分之一）
- 更细分：左/中/右 × 前/中/后 = 9个区域

**指标**：
| 指标 | 定义 | 意义 |
|------|------|------|
| Possession % by Zone | 各区域控球占比 | 控球重心 |
| Average Possession Height | 平均控球高度 | 整体推进程度 |
| Final Third Entries | 进入前场次数 | 推进能力 |
| Touches in Box | 禁区内触球次数 | 进攻威胁 |

**战术意义**：
- 后场控球多 = 从后场组织或被动防守
- 中场控球多 = 中场争夺
- 前场控球多 = 进攻施压
- 平均高度高 = 整体阵型靠前

**训练关联**：
- 各区域的控球训练
- 区域攻防训练
- 阵型推进训练

## 控球指标速查表

| 指标 | 衡量什么 | 高了说明什么 | 低了说明什么 |
|------|---------|-------------|-------------|
| OBV | 触球价值 | 每次触球创造价值 | 触球效率低 |
| Progressive Passes | 纵向推进 | 打法直接 | 横向传导多 |
| Line-Breaking Passes | 破线能力 | 穿透力强 | 缺少纵深威胁 |
| Ball Receipts in Space | 空位接球 | 跑位好 | 被盯防紧 |
| xPass 完成率 | 传球质量 | 传球精度高 | 传球精度低 |
| 前场控球% | 进攻控球 | 施压能力强 | 进攻乏力 |
| 平均控球高度 | 整体推进 | 阵型靠前 | 阵型靠后 |
