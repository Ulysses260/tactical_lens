# 定位球指标 (Set Piece Metrics)

## 1. Corner Kicks 角球

**StatsBomb 事件**：`Corner` (type of pass/set piece)

**细分维度**：
| 维度 | 分类 |
|------|------|
| 发球方式 | 短角球 / 长传角球 / 战术角球 |
| 旋转方向 | 外旋 (Outswinging) / 内旋 (Inswinging) / 不旋转 (Straight) |
| 落点区域 | 前点 / 中间 / 后点 |
| 结果 | 直接射门 / 头球 / 被解围 / 重新控球 |

**指标**：
| 指标 | 定义 | 意义 |
|------|------|------|
| Corner xG | 角球创造的预期进球 | 角球进攻质量 |
| Corner Shot % | 角球直接射门比例 | 角球直接威胁 |
| Corner Header % | 角球头球比例 | 高空进攻依赖度 |
| Short Corner % | 短角球比例 | 战术多样性 |
| Corner Conceded xG | 角球被创造的xG | 角球防守质量 |

**战术意义**：
- 外旋角球 → 前点攻击（更容易直接攻门/摆渡）
- 内旋角球 → 中间/后点（球向球门方向旋转）
- 短角球 → 重新组织、减少传中
- 角球防守成功率低 → 站位/盯人体系有问题

**训练关联**：
- 角球进攻套路训练（3-5种固定配合）
- 前点/后点跑位训练
- 头球攻门训练
- 角球防守站位训练（区域/盯人/混合）

## 2. Free Kicks 任意球

**StatsBomb 事件**：`Free Kick` (type)

**分类**：
| 类型 | 定义 |
|------|------|
| Direct Free Kick | 直接任意球（可直接射门） |
| Indirect Free Kick | 间接任意球（需传球后再射） |
| Wide Free Kick | 边路任意球（通常传中） |
| Central Free Kick | 中路任意球（可射门） |

**指标**：
| 指标 | 定义 |
|------|------|
| Direct FK xG | 直接任意球射门xG |
| FK Shot % | 任意球射门比例 |
| FK Cross Accuracy | 任意球传中准确率 |
| FK Conceded % | 被创造任意球比例 |

**战术意义**：
- 直接任意球 xG 高 = 有优秀的任意球手
- 间接任意球多 = 战术配合设计
- 犯规多在危险区域 = 纪律问题或防守策略问题

**训练关联**：
- 任意球射门训练
- 任意球配合套路训练
- 人墙训练
- 防守任意球站位训练

## 3. Throw-ins 界外球

**StatsBomb 事件**：`Throw In`

**分类**：
| 类型 | 定义 |
|------|------|
| Short Throw | 短界外球 |
| Long Throw | 长界外球（手榴弹战术） |
| Quick Throw | 快发界外球 |

**指标**：
| 指标 | 定义 | 意义 |
|------|------|------|
| Throw-in Retention % | 界外球保留率 | 界外球后是否丢失球权 |
| Long Throw xG | 长界外球创造xG | 手榴弹战术威胁 |
| Quick Throw Usage | 快发界外球使用率 | 比赛节奏控制 |

**战术意义**：
- 长界外球 = 特殊战术（类似角球效果）
- 快发界外球 = 利用对方防守未到位
- 界外球保留率低 = 界外球处理能力差

**训练关联**：
- 长界外球投掷训练
- 快发界外球训练
- 界外球接应跑位训练

## 4. Goal Kicks 球门球

**StatsBomb 事件**：`Goal Kick`

**分类**：
| 类型 | 定义 |
|------|------|
| Short Goal Kick | 短球门球（传给后卫） |
| Long Goal Kick | 长球门球（直接找前锋） |

**指标**：
| 指标 | 定义 | 意义 |
|------|------|------|
| Short GK Retention % | 短球门球保留率 | 后场出球能力 |
| Long GK Won % | 长球门球争顶成功率 | 空中对抗能力 |
| GK Build-up % | 球门球组织进攻比例 | 后场组织偏好 |

**战术意义**：
- 短球门球为主 = 后场组织打法（需要后卫有好的传球能力）
- 长球门球为主 = 直接打法（依赖前锋争顶）
- 短球门球丢失率高 = 被对方高位压迫限制

**训练关联**：
- 后场出球训练（应对高位压迫）
- 门将发球训练
- 前锋/后卫高空对抗训练

## 5. Penalty Kicks 点球

**StatsBomb 事件**：`Penalty`

**指标**：
| 指标 | 定义 |
|------|------|
| Penalty Conversion % | 点球转化率 |
| Penalties Won | 创造点球数 |
| Penalties Conceded | 被判罚点球数 |

**战术意义**：
- 创造点球多 = 禁区内侵略性强
- 被判罚点球多 = 禁区内防守纪律差

**训练关联**：
- 点球训练
- 禁区内防守纪律训练
- 禁区突破训练

## 定位球综合指标速查表

| 指标 | 衡量什么 | 高了说明什么 | 低了说明什么 |
|------|---------|-------------|-------------|
| 角球xG | 角球进攻质量 | 角球战术有效 | 角球战术无效 |
| 角球防守xG | 角球防守质量 | 角球防守差 | 角球防守好 |

| 点球转化率 | 点球能力 | 点球训练充分 | 点球能力弱 |

## 定位球训练方法速查

### 角球进攻训练
1. **前点摆渡**：外旋角球 → 前点头球摆渡 → 后点包抄
2. **后点突袭**：内旋角球 → 后点跑位 → 头球攻门
3. **短角球配合**：短角球 → 倒三角回传 → 远射
4. **区域攻击**：角球落点预设 → 多人区域包抄

### 角球防守训练
1. **区域防守**：每个区域指定1-2人负责
2. **盯人防守**：指定球员盯防对方关键球员
3. **混合防守**：前点区域+后点盯人
4. **反击准备**：解围后立即转入反击
