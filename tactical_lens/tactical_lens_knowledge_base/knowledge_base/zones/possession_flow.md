# 球权流动模式 (Possession Flow Patterns)

## 核心概念

球权流动分析不是看"控球率多少"，而是看**球从哪里开始、到哪里结束、走什么路径**。

这直接反映球队的战术意图和进攻方式。

---

## 1. 球权起始-结束分析

**定义**：追踪每次球权（possession）的起始位置和结束位置。

**StatsBomb 数据**：
- 每次 possession 的 `possession_team` 起始事件和结束事件
- `location` 字段提供坐标

**分析维度**：

```
球权起始位置           球权结束位置
─────────           ─────────
后场 → 后场 (回收)     = 无推进
后场 → 中场 (推进)     = 中等推进
后场 → 前场 (长传)     = 直接推进
中场 → 前场 (组织)     = 阵地推进
前场 → 射门 (终结)     = 进攻完成
任意位置 → 丢球       = 球权丢失
```

**关键指标**：

| 指标 | 定义 | 意义 |
|------|------|------|
| 平均起始位置 | 每次球权开始的平均X坐标 | 整体阵型高低 |
| 平均结束位置 | 每次球权结束的平均X坐标 | 进攻推进深度 |
| 平均推进距离 | 结束位置 - 起始位置 | 每次球权的推进效率 |
| 到达前场% | 球权结束在前场的比例 | 进攻频率 |
| 射门转化% | 球权以射门结束的比例 | 进攻效率 |

## 2. 横向转移分析

**定义**：球从左路转移到右路（或反之）的频率和模式。

**StatsBomb 数据**：`Pass` 事件中 `pass_switch = true`

**指标**：

| 指标 | 定义 | 意义 |
|------|------|------|
| Switch Frequency | 横向转移次数 | 转移球频率 |
| Switch Success % | 转移成功率 | 转移球质量 |
| Left→Right vs Right→Left | 方向比例 | 进攻重心 |
| Switch to Shot | 转移后射门 | 转移球有效性 |

**战术意义**：
- 高转移频率 = 利用宽度、调动对手
- 单向转移多 = 进攻偏向一侧
- 转移后射门多 = 转移球战术有效

**训练关联**：
- 长传转移训练
- 弱侧跑位训练
- 大范围调度训练

---

## 3. 纵向推进分析

**定义**：球从后向前的推进路径和效率。

**指标**：

| 指标 | 定义 | 意义 |
|------|------|------|
| Progressive Passes | 推进传球次数 | 纵向推进能力 |
| Progressive Carries | 推进带球次数 | 个人推进能力 |
| Line-Breaking Passes | 破线传球次数 | 穿透能力 |
| Passes into Final Third | 进入前场传球 | 前场渗透能力 |
| Passes into Box | 进入禁区传球 | 创造机会能力 |

**路径分析**：
```
路径A：后场 → 短传组织 → 中场 → 短传推进 → 前场 → 射门
       （阵地进攻，控球型打法）

路径B：后场 → 长传 → 前场 → 射门
       （直接打法，长传冲吊）

路径C：后场 → 快速推进 → 前场 → 射门
       （快速反击，转换打法）

路径D：后场 → 边路推进 → 传中 → 射门
       （边路打法，传中战术）
```

## 4. 球权流动热力图

**构建方式**：
1. 收集所有传球事件的起点和终点坐标
2. 在球场网格上统计传球密度
3. 生成热力图

**分析要点**：
- 高密度区域 = 进攻重心
- 低密度区域 = 被忽视的区域
- 热区连接 = 核心传球路线

---

## 5. 进攻方向偏好

**定义**：球队进攻偏向左路/中路/右路的程度。

**计算方式**：
```
左侧进攻% = 左侧传球+带球次数 / 总进攻动作次数
中路进攻% = 中路传球+带球次数 / 总进攻动作次数
右侧进攻% = 右侧传球+带球次数 / 总进攻动作次数
```

**典型分布**：
| 类型 | 左 | 中 | 右 | 说明 |
|------|---|---|---|------|
| 均衡型 | 35% | 30% | 35% | 左右均衡 |
| 左倾型 | 45% | 25% | 30% | 左路进攻为主 |
| 右倾型 | 30% | 25% | 45% | 右路进攻为主 |
| 中路由 | 25% | 50% | 25% | 中路渗透为主 |

**战术意义**：
- 偏向一侧 = 该侧有强点（如左边锋、右后卫）
- 均衡 = 进攻灵活、难以预判
- 中路为主 = 控球渗透打法

**训练关联**：
- 针对强侧：配合默契训练
- 针对弱侧：提高弱侧进攻能力
- 针对均衡：保持战术灵活性

## 6. 球权持续时间分析

**定义**：每次球权持续的时间长度。

**分类**：
| 类型 | 持续时间 | 说明 |
|------|---------|------|
| 快速球权 | <10秒 | 反击/快攻 |
| 中速球权 | 10-25秒 | 半转换/快速组织 |
| 慢速球权 | >25秒 | 阵地进攻 |

**指标**：
| 指标 | 定义 | 意义 |
|------|------|------|
| 平均球权持续时间 | 所有球权的平均时长 | 整体节奏 |
| 快速球权占比 | <10秒球权比例 | 反击频率 |
| 慢速球权xG | 阵地进攻创造的xG | 阵地进攻效率 |

---

## 7. 传球网络分析

**定义**：球员之间的传球关系图。

**构建方式**：
- 节点 = 球员
- 边 = 两人之间的传球次数（或传球xG总值）
- 边粗细 = 传球频率

**分析方法**：
- **核心连接**：传球次数最多的2-3对球员
- **孤立球员**：接球/传球极少的球员
- **网络密度**：整体传球分布是否均衡
- **传球方向**：是否主要向前/向后/横向

**战术意义**：
- 核心连接反映战术重心
- 孤立球员可能是战术漏洞或被盯防
- 网络密度反映配合流畅度
