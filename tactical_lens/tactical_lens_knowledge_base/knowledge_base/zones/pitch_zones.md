# 场地分区定义 (Pitch Zones)

## 基础三区划分

StatsBomb 和大多数数据商使用的标准场地分区：

```
┌─────────────────────────────────────────┐
│              防守三区 (Defensive Third)    │
│           本方球门方向 ← 25% 场长        │
├─────────────────────────────────────────┤
│              中场三区 (Middle Third)       │
│           球场中部 ← 50% 场长            │
├─────────────────────────────────────────┤
│              进攻三区 (Attacking Third)    │
│           对方球门方向 ← 25% 场长        │
└─────────────────────────────────────────┘
```

**StatsBomb 坐标系**：
- X轴：0（本方球门线）→ 120（对方球门线），单位：码
- Y轴：0（左侧边线）→ 80（右侧边线），单位：码
- 防守三区：X = 0-40
- 中场三区：X = 40-80
- 进攻三区：X = 80-120

## 九宫格分区（3×3）

结合纵向三区和横向三列：

```
┌──────────┬──────────┬──────────┐
│ 左后场    │ 中后场    │ 右后场    │
│ L-DEF    │ C-DEF    │ R-DEF    │
├──────────┼──────────┼──────────┤
│ 左中场    │ 中中场    │ 右中场    │
│ L-MID    │ C-MID    │ R-MID    │
├──────────┼──────────┼──────────┤
│ 左前场    │ 中前场    │ 右前场    │
│ L-ATT    │ C-ATT    │ R-ATT    │
└──────────┴──────────┴──────────┘
```

**战术意义**：
- **C-ATT（中前场）**：最重要的进攻区域，射门xG最高
- **L-MID / R-MID**：边路组织区域
- **C-DEF（中后场）**：组织发起区域
- **L-DEF / R-DEF**：边后卫活动区域

## 特殊区域定义

### 半空间 (Half Spaces)

```
┌───────────────────────────────────┐
│ 边路 │ 半空间 │ 中路 │ 半空间 │ 边路  │
│ Wing │  H-S   │ Mid  │  H-S   │ Wing │
└───────────────────────────────────┘
```

**定义**：中路与边路之间的区域，大约在场地的1/4和3/4处。

**战术意义**：
- 半空间是创造机会的关键区域
- 接球后可以向内（直塞/射门）也可以向外（传中）
- 现代足球战术的核心区域（如瓜迪奥拉的战术体系）

### 禁区 (Penalty Area / Box)

**StatsBomb 定义**：
- 大禁区：距球门线18码（16.5米），宽44码（40.3米）
- 小禁区：距球门线6码（5.5米），宽20码（18.3米）
- 在StatsBomb坐标系中：X ≈ 102-120, Y ≈ 18-62

### 危险区域 (Danger Zone)

**常用定义**：禁区中央区域，射门xG最高的区域。
- 位置：正对球门，距球门6-12码
- StatsBomb坐标：X ≈ 108-114, Y ≈ 30-50

### 通道 (Channels)

**定义**：防守球员之间的间隙。

**常见通道**：
- **边后卫与中后卫之间**：最常见的进攻渗透通道
- **中场线之间**：前腰活动区域
- **防线身后**：直塞球的目标区域

## 球权区域分析维度

### 按区域统计

| 维度 | 指标 | 意义 |
|------|------|------|
| 控球 | Possession % by Zone | 各区域控球时间占比 |
| 传球 | Pass Accuracy by Zone | 各区域传球成功率 |
| 推进 | Progressive Actions by Zone | 各区域推进动作频率 |
| 威胁 | xG by Zone | 各区域创造的xG |
| 压迫 | Pressures by Zone | 各区域压迫频率 |
| 丢球 | Turnover by Zone | 各区域丢球频率 |

### 区域特征对照

| 区域 | 特征 | 关键能力 |
|------|------|---------|
| 后场 | 需要安全出球、应对压迫 | 控球、传球、抗压 |
| 中场 | 需要控制节奏、推进 | 传球选择、接应跑位 |
| 前场 | 需要创造力、终结 | 最后一传、射门、1v1 |
| 边路 | 需要突破、传中 | 1v1过人、传中质量 |
| 中路 | 需要穿透、配合 | 直塞、接应、跑位 |
| 半空间 | 需要决策、多变 | 传射选择、跑位意识 |
| 禁区 | 需要终结、抢点 | 射门、头球、抢位 |

## 区域训练对应

| 区域 | 数据发现问题 | 对应训练 |
|------|-------------|---------|
| 后场 | 出球成功率低 | 后场组织训练、应对压迫训练 |
| 中场 | 推进传球少 | 中场配合训练、破线传球训练 |
| 前场 | xG低 | 进攻三区决策训练、射门选择训练 |
| 边路 | 传中成功率低 | 传中训练、1v1突破训练 |
| 中路 | 渗透能力弱 | 直塞训练、跑位训练 |
| 半空间 | 利用率低 | 半空间接应训练、传射选择训练 |
| 禁区 | 终结效率低 | 射门训练、抢点训练 |
