# 数据→洞察→训练 映射框架

## 核心逻辑

```
比赛数据 → 指标计算 → 问题识别 → 战术洞察 → 训练匹配 → 教案输出
```

**关键原则**：
- 数据是线索，不是结论
- 每个数据发现都需要视频验证
- 训练方案必须可执行、可测量

---

## 第一层：数据→问题识别

### 进攻类问题

| 数据发现 | 问题描述 | 验证方式 |
|---------|---------|---------|
| xG高但进球少 | 终结效率低 | 看射门视频，检查射门选择和质量 |
| 射门数多但xG低 | 射门选择差 | 看射门位置分布 |
| 前场传球成功率低 | 进攻三区传接球质量差 | 看传球视频，检查压力和决策 |
| 推进传球少 | 缺少纵向穿透 | 看传球网络，检查横向vs纵向比例 |
| 传中成功率低 | 边路进攻效率低 | 看传中视频，检查传中质量和落点 |
| 大机会转化率低 | 把握机会能力差 | 看大机会视频，检查终结质量 |

### 防守类问题

| 数据发现 | 问题描述 | 验证方式 |
|---------|---------|---------|
| PPDA高 | 压迫强度不足 | 看压迫视频，检查压迫时机和协调 |
| 抢断成功率低 | 防守效率差 | 看抢断视频，检查时机和位置 |
| 被突破次数多 | 1v1防守能力弱 | 看1v1视频，检查防守技巧 |
| 被传中次数多 | 边路防守薄弱 | 看边路防守视频 |
| 角球失球多 | 定位球防守差 | 看角球防守视频，检查站位 |
| 禁区内被射门多 | 禁区防守漏洞大 | 看禁区内防守视频 |

### 转换类问题

| 数据发现 | 问题描述 | 验证方式 |
|---------|---------|---------|
| 丢球后反抢成功率低 | 反抢能力弱 | 看反抢视频，检查反抢时机 |
| 反击射门少 | 反击效率低 | 看反击视频，检查推进速度 |
| 转换失球多 | 转换防守差 | 看转换防守视频 |
| 后场出球成功率低 | 后场组织弱 | 看出球视频，检查压迫应对 |

## 第二层：问题→战术洞察

### 洞察框架

对每个问题，问以下问题：

1. **为什么会这样？**（根因分析）
2. **是技术问题还是战术问题？**（分类）
3. **是个人问题还是团队问题？**（范围）
4. **是持续性问题还是特定对手问题？**（普遍性）

### 洞察模板

```
【问题】：{数据发现}
【验证】：{视频证据}
【根因】：{技术/战术/体能/心理}
【范围】：{个人/小组/全队}
【洞察】：{具体描述}
【建议】：{训练方向}
```

### 示例

```
【问题】：角球防守失球3个，角球被创造xG 2.1
【验证】：回看视频发现后点区域无人盯防，防守站位过于平行
【根因】：战术问题——防守体系设计缺陷
【范围】：团队问题——整体防守体系
【洞察】：角球防守采用纯区域防守，后点区域缺少盯人保护，
       对方后点跑位无人跟防
【建议】：改为区域+盯人混合防守，指定专人盯防后点跑位
```

| 边路进攻弱 | 边路训练 | training/by_zone.md#边路 |
| 半空间利用低 | 半空间训练 | training/by_zone.md#半空间 |

### 训练匹配逻辑

```python
def match_training(insight):
    """根据洞察匹配训练方案"""
    
    # 问题分类
    if insight.category == "attacking":
        if insight.zone == "final_third":
            return ["训练A1: 射门选择", "训练A2: 终结"]
        elif insight.zone == "wide":
            return ["训练W1: 边路突破", "训练W2: 套边配合"]
        elif insight.problem == "progression":
            return ["训练M1: 破线传球", "训练M2: 中场推进"]
    
    elif insight.category == "defending":
        if insight.zone == "defensive_third":
            return ["训练D1: 后场防守", "训练D2: 阵型保持"]
        elif insight.problem == "pressing":
            return ["训练14: 前场反抢", "训练15: 压迫+进攻"]
        elif insight.problem == "set_piece":
            return ["训练19: 角球进攻", "训练20: 角球防守"]
    
    elif insight.category == "transition":
        if insight.problem == "counter_attack":
            return ["训练17: 快速转换"]
        elif insight.problem == "counter_press":
            return ["训练18: 丢球反抢"]
```

## 完整流程示例

### 案例：某队角球防守问题

**Step 1: 数据发现**
```
- 角球失球：3个（联赛平均1.2个）
- 角球被创造xG：2.1
- 后点区域被射门：6次
- 角球防守成功率：45%
```

**Step 2: 问题识别**
```
- 问题：角球防守效率严重低于平均
- 重点区域：后点防守漏洞
```

**Step 3: 视频验证**
```
- 回看6个后点射门视频
- 发现：5次后点区域无人盯防
- 防守体系：纯区域防守，后点只安排1人
```

**Step 4: 战术洞察**
```
- 根因：防守体系设计缺陷
- 洞察：纯区域防守在后点区域人数不足，
       对方后点跑位时缺少跟防
```

**Step 5: 训练匹配**
```
- 训练方向：角球防守体系改进
- 具体训练：
  1. 训练20：角球防守站位（区域+盯人混合）
  2. 指定专人盯防后点跑位
  3. 增加后点区域防守人数
```

**Step 6: 教案输出**
```
训练主题：角球防守改进
目标：将角球防守成功率从45%提升到70%

主体训练：
1. 角球防守站位演练（20分钟）
   - 5v5 禁区攻防
   - 区域+盯人混合防守
   - 后点指定专人盯防
   
2. 后点保护专项（15分钟）
   - 后点跑位识别训练
   - 跟防练习
   - 解围方向训练
```

## 自动化思路

如果要实现自动化（战术透镜产品化）：

```
输入：比赛数据（StatsBomb/Opta格式）
  ↓
[模块1] 指标计算引擎
  - 计算所有核心指标
  - 与联赛平均值对比
  ↓
[模块2] 异常检测
  - 识别显著偏离平均的指标
  - 标记为"问题"
  ↓
[模块3] 区域分析
  - 确定问题发生的区域
  ↓
[模块4] 训练匹配
  - 根据问题类型+区域匹配训练方案
  ↓
[模块5] 教案生成
  - 填充教案模板
  - 生成图示
  ↓
输出：训练教案
```

**人工介入点**：
- 视频验证（模块2后）
- 洞察确认（模块3后）
- 教案审核（模块5后）

## 关键设计决策

### 1. 指标阈值怎么定？

**建议**：
- 使用联赛平均值作为基准
- 偏离1个标准差 = 轻度问题
- 偏离2个标准差 = 显著问题
- 结合教练经验调整

### 2. 训练方案谁来做？

**建议**：
- 初始版本：人工编写（基于本知识库）
- 后续迭代：收集教练反馈，优化匹配规则
- 最终形态：教练可以自己添加训练方案

### 3. 图示怎么生成？

**建议**：
- 初期：手动绘制
- 中期：代码生成（Python matplotlib + 球场模板）
- 长期：自动生成（根据训练内容自动绘制）
